# 📚 Data Structures Using C++

A comprehensive collection of **Data Structures** implemented in **C++**, designed to help students build a strong foundation in DSA concepts. This repository contains well-structured implementations of fundamental data structures along with easy-to-understand code, making it an excellent resource for learning, revision, interview preparation, and academic practice.

## 🚀 Features

* Clean and beginner-friendly C++ implementations
* Covers fundamental Data Structure concepts
* Well-organized source code
* Easy to compile and execute
* Suitable for college coursework and coding interview preparation
* Great reference for practicing DSA with C++

## 📂 Topics Covered

* Arrays
* Linked Lists
* Stacks
* Queues
* Trees
* Graphs
* Searching Algorithms
* Sorting Algorithms
* Recursion
* Other fundamental DSA concepts

> *More implementations and algorithms can be added as the repository grows.*

## 🛠️ Technologies Used

* **Language:** C++
* **Compiler:** GCC / G++
* **IDE:** VS Code, Code::Blocks, Dev-C++, or any C++ IDE

## ▶️ Getting Started

Clone the repository:

```bash
git clone https://github.com/Harshalbhatt2806/Data-Structure-Using-Cpp.git
```

Navigate to the project folder:

```bash
cd Data-Structure-Using-Cpp
```

Compile any C++ file:

```bash
g++ filename.cpp -o output
```

Run the program:

```bash
./output
```
